# SKILL-FIRST架构与基于GIT的AI智能体记忆系统

方法论精要基于康斯坦丁·克雷斯特尼科夫（Konstantin Krestnikov）的技术报告：《基于Git的技能：AI智能体的新记忆》（https://www.youtube.com/watch?v=a-NIeMB-Hj8）。

---

## 1. 传统RAG的局限性与向GIT技能的范式转变

在生产环境中，依赖外部向量数据库（RAG / Vector DB）作为智能体长期记忆存在根本性缺陷：

1. 概率性检索与确定性诉求的矛盾：
   余弦相似度检索基于语义接近度，无法保证逻辑完整性、实时有效性与结构契约。智能体经常检索到陈旧或不相干的信息。

2. 缺失版本历史与时序溯源：
   向量数据库无法回答规则何时变更、修改者是谁以及旧规程为何被废弃。

3. 静态文本缺乏执行力：
   向量库检索出的文本是静态被动的，迫使大模型消耗昂贵的推理Token去解析甚至最基础的机械运算。

## 2. SKILL-FIRST架构：以仓库作为记忆基本单元

在Skill-First架构下，每一个技能都是一个完备的自治Git仓库：

```text
+-------------------------------------------------------------+
|                         GIT 仓库                            |
|                                                             |
|  [SKILL.md]     -> 技能护照、触发条件与操作规程             |
|  [scripts/]     -> 可执行确定性工具（承担底层机械运算）     |
|  [data/]        -> 实际工作数据、实体记录与业务产物         |
|  [templates/]   -> 严格数据模式与实体契约原型               |
|  [checks/]      -> 反压验证回路（CI/CD自动拦截）            |
|  [.git/]        -> 不可篡改的审计追踪与演变历史             |
+-------------------------------------------------------------+
```

### 核心竞争优势：
- 确定性精准获取：智能体通过原生文件检索指令（`grep`、`find`、`read_file`）直接按需抽取片段，杜绝上下文膨胀。
- 确定性工具卸载：机械性数据清洗与解析交由本地脚本（Python/Bash）处理，将宝贵算力留给高阶推理。
- 多端智能体同仓协作：桌面端重型Agent（Claude Code、Antigravity、Cursor）与移动端轻量Agent（Hermes、Telegram Bot）围绕同一Git仓库协同，由Git处理版本同步与冲突合并。
- 反压阻断机制：本地CI/CD脚本自动校验数据模式与业务规则，拒绝不合规的提交。

## 3. 上下文经济学与智能区法则（前30%）

实证表明，大语言模型的推理质量随着上下文窗口占用的增加呈现非线性衰退：

- **0% - 30% 窗口（智能区）**：思维敏锐度最高，严格遵守系统指令，幻觉率最低。
- **30% - 70% 窗口**：注意力逐渐分散，容易忽略边界条件。
- **70%+ 窗口**：进入失效区，复杂结构化输出频繁崩溃。

### 上下文管理原则：
严禁在主对话流中直接读取未经过滤的庞大数据。所有信息提炼均委派给本地脚本或沙箱子智能体。

## 4. 智能体循环工程体系 (LOOP ENGINEERING)

为了支撑7x24小时全自动运行（暗黑工厂模式），智能体执行流程分为三层嵌套循环：

### 第1层：内循环 (Inner Loop)
处理单项子任务和具体工具调用的常规推理闭环。

### 第2层：外循环 (Ralph Loop)
跨运行周期、重置上下文的自主迭代闭环：
- 状态通过磁盘文件 `STATE.md` 固化；
- 每次迭代仅提出一个可验证假设，并通过客观测试集或基准评估；
- 指标改善 -> `git commit` 并更新状态文件；
- 发生倒退 -> `git reset --hard HEAD` 强制回滚并重置上下文。

### 第3层：元循环 (Meta Loop / 防死锁)
当连续3次迭代指标停滞、陷入思维死锁时：
- 将现有产物归档至 `archive/attempt_N/`；
- 彻底恢复至基线代码状态；
- 强制禁用原有思路，在正交维度上另起炉灶构建新方案；
- 跑通新方案后再调阅归档，融合双向优势。
